# 전세 임장 노트 (2단계)

네이버 부동산 매물 내용을 붙여넣어 정리하고, 임장 기록과 중개사 메모를 남기는 앱입니다.
화면은 GitHub Pages, 데이터는 구글 스프레드시트(Apps Script)에 저장합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 |
| `parser.js` | 네이버 부동산 텍스트 인식 |
| `config.js` | Apps Script 웹앱 주소 |
| `apps-script/Code.gs` | 백엔드 (스프레드시트에 붙여넣는 코드) |

## 설치 순서

### 1. 스프레드시트와 백엔드

1. 구글 스프레드시트를 새로 만듭니다.
2. **확장 프로그램 > Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. 위쪽 함수 목록에서 `setup`을 고르고 **실행**합니다. 권한 승인 창이 뜨면 허용합니다. `매물`, `중개사`, `임장` 시트가 생깁니다.
4. **배포 > 새 배포 > 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

코드를 고친 뒤에는 **배포 > 배포 관리 > 수정 > 버전: 새 버전**으로 다시 배포해야 반영됩니다.

### 이전 단계에서 올리는 경우

1. Apps Script의 코드를 새 `Code.gs`로 통째로 바꿉니다.
2. `setup`을 다시 실행합니다. 기존 데이터는 그대로 두고 새 시트와 새 열 머리글만 추가합니다.
3. 새 버전으로 다시 배포합니다. 웹 앱 주소는 바뀌지 않습니다.
4. 화면 파일(`app.js`, `style.css`, `parser.js`)을 GitHub에 다시 올립니다.

### 2. 화면 (GitHub Pages)

1. `config.js`의 `API_URL`에 위에서 복사한 주소를 넣습니다.
2. GitHub 저장소에 파일을 올립니다.
3. 저장소 **Settings > Pages**에서 브랜치를 선택해 게시합니다.
4. 게시된 주소로 들어가 이름과 비밀번호를 입력합니다.

`API_URL`을 비워 두면 체험 모드로 열립니다. 이때는 그 브라우저에만 저장되고 비밀번호를 확인하지 않습니다.

## 비밀번호

- 초기 비밀번호는 `Code.gs`의 `INITIAL_PASSWORD`입니다.
- 앱의 **설정 > 비밀번호 변경**에서 바꾸면 스프레드시트의 스크립트 속성에 저장되고, 그때부터 초기 비밀번호는 쓰이지 않습니다.
- 저장소가 공개라면 `Code.gs`를 올릴 때 초기 비밀번호가 함께 공개됩니다. `apps-script` 폴더를 올리지 않거나, 배포 직후 앱에서 비밀번호를 바꾸세요.
- 10번 연속 틀리면 10분 동안 잠깁니다.

## 시트 사용 시 주의

- 열 순서와 머리글은 바꾸지 마세요. 값은 시트에서 직접 고쳐도 됩니다.
- 한 중개사는 `중개사` 시트에 한 줄만 생기고, 등록번호·전화·상호가 같으면 같은 곳으로 묶입니다.
